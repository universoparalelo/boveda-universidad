### TCP
- Protocolo de conexion --> Three way handshake
- Utilizado para conectarse a traves de internet
- Tiene control de errores
- Se preocupa por el orden de llegada de las tramas

### UDP
- No necesita conectarse
- Le importa mas la velocidad que la entrega correcta de datos

### Three way handshake
SYN > SYN ACK > ACK

### Puertos comunes para TCP
21 --> FTP
22 --> SSH
23 --> telnet
25 --> SNMP
53 --> DNS
80 --> HTTP
443 --> HTTPS
110 --> POP3
139, 445 --> SMB
143 --> IMAP
