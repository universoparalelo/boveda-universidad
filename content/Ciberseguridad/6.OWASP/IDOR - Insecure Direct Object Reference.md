> Es una vulnerabilidad web crítica que ocurre cuando una aplicación expone objetos internos (como archivos, registros de bases de datos o identificadores de usuario) sin verificar la autorización. Esto permite a un atacante cambiar un valor en la URL o formulario (ej. `id=100` por `id=101`) para acceder a datos ajenos.
