- [Link del repo](https://github.com/strozfriedberg/PadBuster)

- Descarga el repo
```
git clone https://github.com/strozfriedberg/PadBuster.git
```
- Ingresas y das permiso
```
cd PadBuster
chmod +x padBuster.pl
```
- Descagas dependencias
```
sudo apt install libwww-perl libcrypt-ssleay-perl
```
- Ejecutas
```
./padBuster.pl
```
