## Instalacion
```bash
git clone https://github.com/steverobbins/magescan
cd magescan
```
Debemos descargar [magescan.phar](https://github.com/steverobbins/magescan/releases)
```bash
mv /home/user/Descargas/magescan.phar .
php magescan.phar
```
