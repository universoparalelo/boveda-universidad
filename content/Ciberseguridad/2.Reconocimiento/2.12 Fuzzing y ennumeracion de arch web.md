### Herramientas
- Gobuster
```
gobuster dir -u https://miwifi.com -w archivo/de/lista/spec/listas -t 50 -x html -s 200 -b '' 
```
- wfuzz
```
wfuzz -c -t 200 -w archivo/de/palabras/spec/lists https://miwifi.com/FUZZ
```
Esconder las respuestas 404
```
wfuzz -c --hc=404 -t 200 -w archivo/de/palabras/spec/lists https://miwifi.com/FUZZ
```

Ennumerar archivos
```
wfuzz -c --hc=404 -t 200 -w archivo/de/palabras/spec/lists -z list,html-php-txt-json https://miwifi.com/FUZZ.FUZZZ
```

Ennumerar productos
```
wfuzz -c --hc=404 -t 200 -z range,1-20000 'https://miwifi.com/product?id=FUZZ'
```

- ffuf
```
ffuf -c -mc=200 -t 200 -w diccionario/de/palabras -u https://miwifi.com/FUZZ/ 
```
