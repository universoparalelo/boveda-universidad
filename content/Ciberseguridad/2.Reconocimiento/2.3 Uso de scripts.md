### Encontrar un archivo por un nombre
- .mse es la extension de script de nmap listos para usar
```
locate .nse
```

-sCV: te dice la version y servicio de la ip a escanear y ademas corre unos scripts mas comunes para un escaneo mas detallado
```
nmap -p22 192.168.100.1 -sCV
```

### Para auditar un puerto ftp
ftp-anon.nse

### Para auditar un http
http-robots.txt.nse

### Categorias de nmap
```
locate .nse | xargs grep "categories" | grep -oP '".*?"' | sort -u (| wc -l)
```

### Lanzar script de determinada categoria
```
nmap -p22 192.168.100.1 --script="vuln and safe"
```

### Crear un servidor con python
```
python3 -m http.server 80
```

Escanear si hay un servicio
```
lsof -i:80
```

En que ruta del sistema se ejecuta ese servidor
```
pwdx id_proceso
```
