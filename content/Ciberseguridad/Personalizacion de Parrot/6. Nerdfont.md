- Desde [nerdfont](https://www.nerdfonts.com/font-downloads) descargamos la fuente *Hack Nerd Font*.
- Movemos la fuente
```
mv Hack.zip /usr/local/share/fonts
cd /usr/local/share/fonts
unzip Hack.zip
```

- Para tener una comunicacion bidireccional con la maquina virtual modificamos `~/.config/bspwn/bspwnrc`
```
vmware-user-suid-wrapper &
```

- Instalando *zsh*
```
apt install zsh
```

- Utilizamos un archivo para configurar kitty `~/.config/kitty/kitty.conf`
```
enable_audio_bell no

include color.ini

font_family HackNerdFont
font_size 13

disable_ligatures never

url_color #61afef

url_style curly

map ctrl+left neighboring_window left
map ctrl+right neighboring_window right
map ctrl+up neighboring_window up
map ctrl+down neighboring_window down

map f1 copy_to_buffer a
map f2 paste_from_buffer a
map f3 copy_to_buffer b
map f4 paste_from_buffer b

cursor_shape beam
cursor_beam_thickness 1.8

mouse_hide_wait 3.0
detect_urls yes

repaint_delay 10
input_delay 3
sync_to_monitor yes

map ctrl+shift+z toggle_layout stack
tab_bar_style powerline

inactive_tab_background #e06c75
active_tab_background #98c379
inactive_tab_foreground #000000
tab_bar_margin_color black

map ctrl+shift+enter new_window_with_cwd
map ctrl+shift+t new_tab_with_cwd

background_opacity 0.95

shell zsh
```

- Plugins para zsh
```
apt install zsh-autosuggestions zsh-syntax-highlighting zsh-autocomplete
```

- Para instalar la version mas actualizada de kitty vamos a [kitty github releases](https://github.com/kovidgoyal/kitty/releases/tag/v0.45.0) y descargamos `Linux amd64 binary bundle`
- Para descomprimir y tal
```
cd opt/
mkdir kitty
cd kitty
mv . ~/home/s4vitar/Descargas/kitty_amd64_binary_bundle.txz
7z x kitty_amd64_binary_bundle.txz
tar -xf kitty_amd64_binary_bundle.tar
cd bin/
apt remove kitty
```

- Configuramos el `sxhkdrc` para que abra la nueva version de kitty, no la anterior
- nano /home/s4vitar/.config/sxhkd/sxhkdrc
```
super + Return
	/opt/kitty/bin/kitty
```

- Para tener en root la misma configuracion que en tu usuario
```
sudo su
cd root/.config/kitty/ 
cp /home/s4vitar/.config/kitty/* .
```

## Colocar un fondo de pantalla

- Descargas una imagen
```
cd Descargas/
kitty +kitten icat fondo.png
```

- Instalando `feh`
```
sudo apt install feh
feh --bg-fill fondo.png # para colocar el fondo en el momento al escritorio
```

- Agregamos entonces `feh --bg-fill /home/s4vitar/Descargas/fondo.png &` para que cuando iniciemos la computadora este todo cargado
```
nvim ~/.config/bspwn/bspwnrc
```
