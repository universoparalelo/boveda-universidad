- El archivo de configuracion esta en `~/.config/polybar/launch.ini`
- Las lineas que agrega
```
polybar ethernet_bar -c ~/.config/polybar/current.ini &
polybar victim_target -c ~/.config/polybar/current.ini &
```

- Luego para modificar `ethernet` o `primary` o cualquier modulo que aparezca en la polybar debemos ir a `~/.config/polybar/current.ini`
```
font-7= "Hack Nerd Font Mono":size=13;5

[bar/log]
background= ${color.bg}

[bar/ethernet_bar] # --> antes [bar/secondary]
width = 13%
modules-center = ethernet_status

[bar/victim_target] # --> antes [bar/secondary]
width = 13%
offset-x = 80%
modules-center = target_to_hack

------------------------------------------------------

[module/my-text-label]
content= %{70}😀

[module/ethernet_status]
type = custom/script
interval = 2
exec = ~/.config/bin/ethernet_status.sh

[module/target_to_hack]
type = custom/script
interval = 2
exec = ~/.config/bin/target_to_hack.sh
```

- Creamos un archivo que me muestre la ip todo el tiempo en `~/.config/bin/ethernet_status.sh`
```bash
#!/bin/bash

echo "$(ifconfig ens33 | grep "inet " | awk '{print $2}')"
```
- Creamos `~/.config/bin/target_to_hack.sh`
```bash
#!/bin/bash

ip_address=$(/bin/cat /home/s4vitar/.config/bin/target | awk '{print $1}')
machine_name=$(/bin/cat /home/s4vitar/.config/bin/target | awk '{print $2}')

if [ $ip_address ] && [ $machine_name ]; then
	echo "%{F#e51d0b}ICONO %{F#ffffff}$ip_address%{u-} -$machine_name"
else
	echo "%{F#e51d0b}ICONO %{u-}%{F#ffffff} No target"
fi
```
