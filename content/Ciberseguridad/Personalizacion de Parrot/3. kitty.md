- Instalando kitty
```zsh
apt install kitty
```

- Modificamos el archivo `~/.config/sxkhd/sxkhdrc`
```bash
super + return
	kitty
```

- Utilizar flechas en vez de hjkl
```bash
super + {_,shift + }{Left,Down,Up,Right}
```

- Customizar el resize
```
# se aniaden 
super + alt + {Left,Down,Up,Right}
	/home/s4vitar/.config/bspwn/scripts/resize {west,south,north,east}
```

- Crear el archivo para el resize
```bash
mkdir /home/s4vitar/.conf/bspwn/scripts/
touch /home/s4vitar/.conf/bspwn/scripts/resize
nano /home/s4vitar/.conf/bspwn/scripts/resize
```

- Para obtener el codigo hay que ir a `https://hack4u.io/wp-content/uploads/2025/09/bspwn_resize.txt` desde la web, pero no funca eso ahora, lo descubriremos mas adelante
