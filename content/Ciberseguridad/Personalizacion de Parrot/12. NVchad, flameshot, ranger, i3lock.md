## Insane instalation
```
sudo apt install flameshot ranger
```

- Flameshot es para tomar captura de pantalla y anotar de multiples maneras sobre la misma
```
flameshot gui
# enter
# o te aparece el icono en la polybar
```

- Ranger es para una previsualizacion de archivos en un directorio
```
ranger
```

## sudo plugin zsh
- Agrega sudo delante de un comando
```
mkdri /usr/share/zsh-sudo
chown s4vitar:s4vitar /usr/share/zsh-sudo
cd /usr/share/zsh-sudo
su s4vitar
wget https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/refs/heads/master/plugins/sudo/sudo.plugin.zsh
chmod +x sudo.plugin.zsh
```

- Para poder utilizarla dentro de `~/zshrc` agregamos
```
if [ -f /usr/share/zsh-sudo/sudo.plugin.zsh ]; then 
	source /usr/share/zsh-sudo/sudo.plugin.zsh
fi
```

## nvchad
- nvim pero con esteroides
```
apt install npm
rm -r ~/.config/nvim
git clone https://github.com/NvChad/starter ~/.config/nvim
```
- descargamos nvim en su ultima version [link](git clone https://github.com/NvChad/starter ~/.config/nvim && nvim) el archivo `nvim_linuxamd64.tar.gz`
```
cd /opt
mv /home/s4vitar/Descargas/nvim_linuxamd64.tar.gz .
tar -xf nvim_linuxamd64.tar.gz
rm nvim_linuxamd64.tar.gz
cd nvim_linuxamd64/bin
# como usuario no privilegiado
./nvim
```

- y para ajustar todo
```
sudo apt remove neovim
pwd # te copias la url de ./nvim
```

- Dentro de `~/.zshrc` agregas en la variable **PATH**:
```
export PATH=/usr/local:/opt/nvim-linux-x86_64/bin:$PATH # algo asi es tu archivo
```

- Y para hacerlo con root
```
sudo su
cd ~/.config
rm -rf nvim
cp /home/s4vitar/.config/nvim .
nvim
```
