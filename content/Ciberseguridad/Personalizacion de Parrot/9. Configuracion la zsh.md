- En `https://github.com/romkatv/powerlevel10k` copiamos:
```
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ~/powerlevel10k
echo 'source ~/powerlevel10k/powerlevel10k.zsh-theme' >>~/.zshrc
zsh
```
- Te lleva a traves de un tutorial y eliges tus estilos.

- Para sacar mensajes de bienvenida en la terminal, dentro de  `~/.zshrc`
```
# echo "Welcome to Parrot"
```

- Cambiar configuraciones en powerlevel10k en el archivo `~/.p10k.zsh`
```
typeset -g POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=()
```
- Debajo de esa linea comentamos todo
- Dentro del mismo archivo:
```
typeset -g POWERLEVEL9K_LEFT_PROMPT_ELEMENTS=(
	os_icon
	dir
	vcs
	# agregamos estas tres
	context
	command_execution_time
	status
)
```

- Agregamos toda esa configuracion para root:
```
sudo su
git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ~/powerlevel10k
echo 'source ~/powerlevel10k/powerlevel10k.zsh-theme' >>~/.zshrc
zsh
# aparece un mensaje de error y hacemos ctrl_c
chown root:root /usr/local/share/zsh/site-functions/_bspc
```
- Para que un usuario entre con zsh y no bash
```
usermod --shell /usr/bin/zsh root
usermod --shell /usr/bin/zsh s4vitar
```

## volver a configurar p10k
```
p10k configure
```
