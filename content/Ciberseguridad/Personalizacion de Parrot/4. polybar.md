
- Repo de la polybar
```bash
cd Descargas
git clone --recursive https://github.com/polybar/polybar
cd polybar
mkdir build
cd build
cmake ..
make -j$(nproc)
sudo make install
```

- Deberia funcionar
```
which polybar
```
