Docker es una plataforma de código abierto para crear, desplegar y ejecutar aplicaciones en **contenedores**, que son paquetes ligeros y portátiles que incluyen todo lo necesario (código, bibliotecas, dependencias) para que una app funcione de forma consistente en cualquier entorno (local, nube).

Componentes Clave

- **Contenedor:** Una instancia ejecutable de una imagen; el paquete aislado que contiene la aplicación y sus dependencias.
- **Imagen:** Una plantilla de solo lectura que contiene las instrucciones para crear un contenedor, construida a partir de un `Dockerfile`.
- **[Dockerfile](https://www.google.com/search?q=Dockerfile&rlz=1C1CHBF_enAR1147AR1147&oq=docker&gs_lcrp=EgZjaHJvbWUyDAgAEEUYORixAxiABDIKCAEQABixAxiABDINCAIQABiDARixAxiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIGCAYQRRg9MgYIBxBFGEHSAQc3MjBqMGo3qAIAsAIA&sourceid=chrome&ie=UTF-8&ved=2ahUKEwjPq-euzLWRAxXiILkGHW8HOj8QgK4QegYIAQgAEAs):** Un archivo de texto con las instrucciones para construir una imagen Docker (el "plano").- **[Docker Hub](https://www.google.com/search?q=Docker+Hub&rlz=1C1CHBF_enAR1147AR1147&oq=docker&gs_lcrp=EgZjaHJvbWUyDAgAEEUYORixAxiABDIKCAEQABixAxiABDINCAIQABiDARixAxiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIGCAYQRRg9MgYIBxBFGEHSAQc3MjBqMGo3qAIAsAIA&sourceid=chrome&ie=UTF-8&ved=2ahUKEwjPq-euzLWRAxXiILkGHW8HOj8QgK4QegYIAQgAEA0):** Un registro (repositorio) público y privado para compartir imágenes de Docker.

# Instalacion
`sudo apt install docker.io -y`

# Images
`docker images`
- Archivo que contiene todas las instrucciones para correr maquina/s virtual/es.
- Dentro de ellos se construyen los contenedores.
```
FROM ubuntu:latest

MAINTAINER creador del universo creador_del_universo@gmail.com
```
- Dockerfile ^
### Para montar la imagen
`docker build -t my_first_image .`
### Correr una imagen
`docker run -dit --name myContainer my_first_image`
- -dit le estamos diciendo que corra como un proceso independiente, que sea interactivo mediante una consola y que esos parametros los junte
### Interactuar con el contenedor
`docker exec -it myContainer bash`
### Configurar la maquina 'desnuda'
```
apt update
apt install net-tools -y
apt install iputils-ping -y
```
### Descargar imagenes de la nube
`docker pull debian:latest`
## Imagen actualizada
```
FROM ubuntu:latest

MAINTAINER creador del universo creador_del_universo@gmail.com

RUN apt update && apt install -y net-tools \
	iputils-ping \
	git \
	nano \
	curl 
```
Para construir:
`docker build -t my_first_image:v2 .`
Para correr:
`docker run -dit --name mySecondContainer my_first_image:v2`

## Eliminar imagen
`docker rmi <image-id>`
`docker rmi $(docker images -q)` borra todas las imagenes habidas y por haber
# Contenedores
`docker ps`
`docker ps -a` incluye contenedores que estan parados
`docker rm <container-id>`
`docker rm <container-id> --force` matas contenedores que estan corriendo
`docker rm $(docker ps -a -q) --force` matas todos los contenedores activos y no

## Frenar
`docker stop <container-id>`
