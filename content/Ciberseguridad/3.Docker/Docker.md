> Docker es una plataforma de código abierto para crear, desplegar y ejecutar aplicaciones en **contenedores**, que son paquetes ligeros y portátiles que incluyen todo lo necesario (código, bibliotecas, dependencias) para que una app funcione de forma consistente en cualquier entorno (local, nube).

## Componentes Clave

- **Contenedor:** Una instancia ejecutable de una imagen; el paquete aislado que contiene la aplicación y sus dependencias.
- **Imagen:** Una plantilla de solo lectura que contiene las instrucciones para crear un contenedor, construida a partir de un `Dockerfile`.
- **[Dockerfile](https://www.google.com/search?q=Dockerfile&rlz=1C1CHBF_enAR1147AR1147&oq=docker&gs_lcrp=EgZjaHJvbWUyDAgAEEUYORixAxiABDIKCAEQABixAxiABDINCAIQABiDARixAxiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIGCAYQRRg9MgYIBxBFGEHSAQc3MjBqMGo3qAIAsAIA&sourceid=chrome&ie=UTF-8&ved=2ahUKEwjPq-euzLWRAxXiILkGHW8HOj8QgK4QegYIAQgAEAs):** Un archivo de texto con las instrucciones para construir una imagen Docker (el "plano").
- **[Docker Hub](https://www.google.com/search?q=Docker+Hub&rlz=1C1CHBF_enAR1147AR1147&oq=docker&gs_lcrp=EgZjaHJvbWUyDAgAEEUYORixAxiABDIKCAEQABixAxiABDINCAIQABiDARixAxiABDIHCAMQABiABDIHCAQQABiABDIHCAUQABiABDIGCAYQRRg9MgYIBxBFGEHSAQc3MjBqMGo3qAIAsAIA&sourceid=chrome&ie=UTF-8&ved=2ahUKEwjPq-euzLWRAxXiILkGHW8HOj8QgK4QegYIAQgAEA0):** Un registro (repositorio) público y privado para compartir imágenes de Docker.
