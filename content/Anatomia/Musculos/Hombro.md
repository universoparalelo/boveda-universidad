# Hombro

## Musculos
- **Deltoides anterior** — [[Movimientos/Flexion|flexion]], rotacion interna, aduccion horizontal
- **Deltoides medio** — [[Movimientos/Abduccion-y-Aduccion|abduccion]] (15-90°)
- **Deltoides posterior** — [[Movimientos/Extension|extension]], [[Movimientos/Rotacion|rotacion externa]], abduccion horizontal
- **Supraespinoso** — inicia la abduccion (0-15°), estabiliza cabeza humeral
- **Infraespinoso** — [[Movimientos/Rotacion|rotacion externa]]
- **Redondo menor** — [[Movimientos/Rotacion|rotacion externa]], estabilizacion
- **Redondo mayor** —
- **Subescapular** — [[Movimientos/Rotacion|rotacion interna]]
- **Serrato posterior superior e inferior**

## Movimientos relacionados
- Flexion de hombro → deltoides anterior
- Abduccion → deltoides medio (15-90°), supraespinoso (0-15°)
- Extension de hombro → deltoides posterior
- Rotacion externa → infraespinoso, redondo menor, deltoides posterior
- Rotacion interna → subescapular, deltoides anterior
