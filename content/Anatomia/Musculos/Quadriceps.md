# Quadriceps

## Musculos
- **Recto femoral** — [[Movimientos/Flexion|flexion]] de cadera y [[Movimientos/Extension|extension]] de rodilla
- **Vasto lateral** — extension de rodilla, estabilidad lateral
- **Vasto medial** — extension de rodilla, estabiliza rotula medialmente
- **Vasto intermedio** — extension de rodilla
- **Sartorio**

## Movimientos relacionados
- Extension de rodilla → vastos, recto femoral
- Flexion de cadera → recto femoral
