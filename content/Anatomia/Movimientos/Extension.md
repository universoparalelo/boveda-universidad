# Extension

**Extension = alejar segmentos del cuerpo, abrir el angulo**

## Ejemplos
- Extension de codo → enderezar el brazo
- Extension de cadera → llevar la pierna hacia atras
- Extension de hombro → mover el brazo hacia atras
- Extension de rodilla → estirar la pierna
- Extension de tronco → arquear la espalda

## Musculos que extienden
- Hombro: [[../Musculos/Hombro|Hombro]] (deltoides posterior), [[../Musculos/Espalda|Espalda]] (dorsal ancho)
- Codo: [[../Musculos/Brazo|Brazo]] (triceps)
- Cadera: [[../Musculos/Cadera-gluteos|Cadera]] (gluteo mayor), [[../Musculos/Isquiotibiales|Isquiotibiales]]
- Rodilla: [[../Musculos/Quadriceps|Quadriceps]] (vastos, recto femoral)
- Columna: [[../Musculos/Espalda|Espalda]] (erectores espinales)
