- Usados en python
```
a.sort()
b = sorted(a)
```
- Complejidad = O(n log n) — [[Big O]]
- Ordenar por key
```
a.sort(key=lambda x: x[i])
```
- Ordenar descendente
```
a.sort(reverse=True)
```
- Ordenar strings
```
sorted('cba')
```
