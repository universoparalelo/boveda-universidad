# Lectura paralela (sintopica)

El nivel mas avanzado de lectura. No se trata de leer un libro, sino de leer **multiples libros** sobre un mismo tema y contrastarlos.

## Como se hace
1. Partir de una **pregunta** (ej: "El Estado nace por naturaleza o es algo artificial?")
2. Leer pasajes de distintos autores sobre esa pregunta
3. Comparar enfoques y argumentos
4. Formar una posicion personal

## Ejemplo del libro
Leer parrafos de **Aristoteles** y **Rousseau** sobre el origen del Estado, responder preguntas alrededor del tema, analizar diferencias. Concluir si se esta de acuerdo con alguno.
